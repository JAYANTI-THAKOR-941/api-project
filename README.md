# Product API Practice

React product-management exercise with a local JSON dataset.

## Project structure

`db.json`, `src/ProductManagement.jsx`, `src/App.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/api-project.git
cd api-project
```

Install dependencies with `npm ci`. Start the API according to the package scripts and the application's configured endpoint, then run `npm run dev`.
